# DueFlow

> **Get paid. Without the chasing.**

DueFlow is an automated invoice follow-up platform built for small businesses.

It tracks unpaid invoices, sends smart payment reminders, creates payment links, and alerts business owners about overdue payments, helping them recover money faster without manually chasing clients.

## 🚀 Features

* 📄 Invoice management
* ⏰ Automatic payment reminders
* 🔴 Overdue invoice tracking
* 💳 Payment links
* 📊 Financial dashboard
* 📧 Automated email notifications
* ⚙️ Custom reminder rules
* 📈 Payment recovery tracking

## 🛠️ Tech Stack

* React
* TypeScript
* Tailwind CSS
* Node.js
* Express
* PostgreSQL
* Stripe
* Resend
